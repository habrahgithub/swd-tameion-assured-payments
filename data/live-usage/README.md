# Genuine source data withdrawn

The public source set and evidence ledger contain no records. Genuine financial facts, source fingerprints and auxiliary classifications have been withdrawn for privacy review. This does not assert that the underlying obligations do not exist, and it does not erase historical exposure.

The runtime has no private-source import or synthetic fallback. Test fixtures live only under `tests/test-support` and are invented, non-economic cases. Their legacy identifiers are regression aliases, never genuine usage evidence. No retained namespace or persisted authorization is reset by this withdrawal.
